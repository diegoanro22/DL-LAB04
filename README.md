# Laboratorio 04 — Aprendizaje por Refuerzo con Gymnasium

Material del curso **CC3092 — Deep Learning y Sistemas Inteligentes**.

El notebook explora los fundamentos del aprendizaje por refuerzo, la API de
Gymnasium y los entornos `CartPole-v1` y `FrozenLake-v1`. Incluye una
comparación entre un agente aleatorio y una política heurística para CartPole.

## Requisitos

```bash
pip install gymnasium matplotlib numpy jupyter
```

## Ejecución

Inicia Jupyter y abre el notebook:

```bash
jupyter notebook Laboratorio_04_RL_Gymnasium.ipynb
```

Las ejecuciones usan semillas fijas para facilitar la reproducibilidad.
